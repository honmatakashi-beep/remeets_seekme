## 💰 初期費用（運用開始コスト）＆ ランニングコスト 総合見積もり

本番ローンチに際し、開発から実運用までのコストを**「フェーズ1（完全無料・極限ゼロコスト起動期）」**と**「フェーズ2（商用本格マネタイズ期）」**の2パターンに分け、**「初期コスト（運用開始までにかかる費用）」**と**「ランニングコスト（月額・年額の維持費）」**をまとめました。

### 🟢 パターンA：極限ゼロコスト起動期（フェーズ1）
有料メニューを一切作らずに「完全無料」としてローンチし、特商法表記義務（住所公開）を合法的に回避しつつ、無料枠を徹底的に使い倒すスモールスタートプラン。

#### 【初期コスト（運用開始までにかかるお金）】
* **独自ドメイン取得費用**: **約 1,800円 (年額一括)**
  * SquarespaceやCloudflareドメイン等で `.com` や `.net` を取得する原価費用です（月額換算で約150円）。
* **サーバー・システム初期構築費**: **0円**
  * AI Studio Buildからの1クリックデプロイ、Cloud Run、Supabaseの初期登録・構築はすべて無料で行えます。
* **eKYC・SMS認証システム初期連携費**: **0円**
  * フェーズ1では高価なSMS・eKYCを使用せず、標準搭載の「メール疎通認証」のみで安全に運用するため初期費用はかかりません。
* **特商法表記・住所取得初期費用**: **0円**
  * 販売行為を行わないため、バーチャルオフィスの契約や番号取得は不要です。
* **初期コスト合計**: **約 1,800円 (ドメイン代のみ)**

#### 【ランニングコスト（月額の運営維持費）】
* **ドメイン維持費（月額換算）**: **約 150円 / 月**
* **独自メール窓口 (Google Workspace Starter)**: **816円 / 月**
  * `info@remeets.com` のような独自ドメインのプロ用問い合わせメールアドレスを1口座のみ契約します。
* **サーバー (Google Cloud Run)**: **0円 〜 1,000円 / 月**
  * 無料枠（月200万リクエストまで無料）に余裕で収まるため、立ち上げ初期は実質無料です。
* **データベース (Firebase Sparkプラン/Firestore)**: **0円 / 月**
  * ドキュメント読み取り5万回/日、書き込み2万回/日、容量1GBまでの高性能NoSQLデータベース、および安全なユーザー認証機能（Firebase Auth）が完全無料で使用できます。
* **お問合せ返答メール (Resend Free)**: **0円 / 月**
  * 月3,000通までの配信が完全無料で、到達率も非常に高水準です。
* **セキュリティ・DDoS防御 (Cloudflare Free)**: **0円 / 月**
  * SSL証明書の自動更新やハッカー・悪質Botのアクセス遮断が完全無料です。
* **Gemini AI API (Google AI Studio)**: **0円 〜 500円 / 月**
  * 従量課金。モデレーションAIが実際に動いた文字数（100万トークンあたり数十円〜数百円）のみ支払います。
* **ランニングコスト合計**: **月額 約 966円 〜 2,466円 (実質Workspaceメール代のみ！)**

#### 【初期コスト（運用開始までにかかるお金）】
* **独自ドメイン取得費用**: **約 1,800円 (年額一括)**
* **バーチャルオフィス契約初期費用**: **約 1,500円 〜 3,500円 (契約時のみ)**
  * 郵便転送や法人登記が可能な都内一等地の住所を取得します。
* **050電話番号取得初期費用**: **約 1,000円 (契約時のみ)**
* **決済代行システム（Stripe）アカウント初期登録費**: **0円**
  * 初期費用や月額固定費は完全無料。決済が発生した際の「手数料（約3.6%）」のみの完全成果報酬型です。
* **eKYC本人確認システム（TRUSTDOCK等）初期接続設定費**: **0円 〜 30,000円**
  * M&A時の信頼性を担保する、高セキュリティな本人確認インフラ。
* **初期コスト合計**: **約 4,300円 〜 36,300円**

#### 【ランニングコスト（月額の運営維持費）】
* **ドメイン維持費（月額換算）**: **約 150円 / 月**
* **複数人メール個別運用 (Google Workspace 2口座)**: **1,632円 / 月**
  * 共同運営やカスタマーサポート用の複数口座運用。
* **サーバー (Google Cloud Run)**: **4,000円 〜 8,000円 / 月**
  * 常時最小1アクティブコンテナを確保し、ユーザーがいつアクセスしても「1秒以内」に画面が表示される最高速の体感応答速度を維持します。
* **データベース (Firebase Blazeプラン / Firestore)**: **0円 〜 3,000円 / 月**
  * 無料枠（毎日5万回読込等）を超過した分のみの完全従量課金。大規模なデータ容量への拡張、および自動バックアップ体制を強化。
* **自動配信システム (Resend Pro / SendGrid)**: **約 2,000円 / 月**
  * 月1万通〜4万通の再会マッチングアラート、一斉お知らせメールの配信到達率を保証。

  * 大量に漂流するボトルメールやメッセージを24時間フル稼働でセマンティック分析・監視。
* **特商法表記用・バーチャルオフィス維持費**: **1,500円 〜 3,500円 / 月**

## 📈 財務・コスト適正化に向けた防衛戦略

1. **SMS送信コストの防御設計**
   * SMS送信（Twilio等）はAPIを悪用された場合に膨大な赤字を抱えるリスクがあります。そのため、認証送信を「アカウント作成時」ではなく「eKYC（本人確認）申請時、かつStripeによる決済完了時」のみに配置。これにより、悪意あるBotの大量自動送信アタックを完全に遮断し、送信費用は必ず決済金額内から回収される安全な設計としています。

2. **Firebase Firestore / データベースの圧倒的無料枠＆スケール耐性**
   * Firebaseの「Sparkプラン（無料枠）」は、データ容量1GB（約10万〜30万件のユーザーレコード）に加えて、毎日5万回のドキュメント読み取り、2万回のドキュメント書き込みが永久無料で提供されます。立ち上げ初期はシステム維持費を実質完全にゼロに抑えられます。さらにアクセスが増加した際も、「Blazeプラン（従量課金）」へとスムーズにスケーリングでき、インフラ死やダウンタイムのないシームレスな移行が可能です。

3. **Gemini API 利用制限の安全弁**
   * 各種メッセージ、ボトルメールのAIセマンティックモデレーション（不適切表現や出会い目的、個人情報の検閲）において、APIキーの1分あたりのクォータ制限を設定することで、予期せぬAPI利用費の急騰を防ぎます。
